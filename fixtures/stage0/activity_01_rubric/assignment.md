# Actividad: politica de cache

Explique una politica de cache para un servicio de consulta. El entregable debe describir el orden de lectura, la invalidacion y el comportamiento cuando la fuente principal no responde.

## Restricciones

- No ejecute servicios externos.
- Distinga los datos observados de los supuestos.
- Incluya al menos una limitacion defendible desde el diseno presentado.
