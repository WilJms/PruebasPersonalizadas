# Extensiones futuras del corpus

Estos puntos quedan fuera del corpus core congelado y solo deberían incorporarse mediante un extension set versionado por separado:

- pares de submissions del mismo nivel con enfoques distintos;
- PDF escaneado y OCR imperfecto;
- consignas deliberadamente breves o muy ambiguas;
- contradicción accidental entre assignment y rubric para distinguir `INTENTIONAL_AMBIGUITY` de `CORPUS_DEFECT`;
- fallos reales de subida, artefactos parcialmente vacíos o formatos dañados;
- mayor cobertura de `P06_UNCERTAIN` en trabajos de calidad media.

No se añadieron nuevas submissions en esta finalización y no se introdujo ningún corpus defect intencional en el core.
